# VS-R1-003 — Canonical Destination and Product Offer

## Documents

1. [Slice Specification](./SLICE_SPEC.md)
2. [Acceptance Checklist](./ACCEPTANCE_CHECKLIST.md)

## Executable outcome

The slice proves that Platform Administration can:

- Create a canonical Region.
- Create a canonical Destination within an active Region.
- Create a supplier-independent Product.
- Create a draft Product Offer covering one or more Destinations.
- Publish the Product Offer.
- Read localized offer data with English fallback.
- Suspend the Product Offer.
- Prevent duplicate catalog codes.
- Persist canonical catalog state and activity in PostgreSQL.
