## Executable outcome

The slice proves that:

- The YSim platform organization exists.
- Platform bootstrap administration can create an agency.
- An agency can be activated.
- A principal can be granted an agency role.
- Organization context resolves only for an active membership.
- Cross-agency access is denied.
- Organization activity is recorded.
- The result runs against a real PostgreSQL database and real API process.
