## Executable outcome

The slice proves that:

- A signed server-side agency session is required.
- The selected organization context is verified by YSim Platform API.
- An active agency member sees the Agency Portal shell.
- Agency Admin and Agency User receive role-aware navigation.
- Draft and suspended organizations receive explicit unavailable states.
- Cross-agency access receives a denied state.
- The dashboard deliberately contains no revenue, order or commission data.
- A real Next.js production server and Chromium browser execute the scenario.
