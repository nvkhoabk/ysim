# YSF — YSim Software Factory

YSF is the production toolchain used to operate the YSim AI Software Factory.

## Initial commands

```bash
ysf --version
ysf doctor
ysf doctor --json
```

## Planned commands

```bash
ysf build-index
ysf build-knowledge
ysf build-context
ysf build-prompt
ysf validate
ysf run
ysf report
```

During migration, the existing scripts under scripts/ remain supported.
